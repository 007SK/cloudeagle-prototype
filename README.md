# CloudEagle AI Integration Builder

Interactive product prototype by Swati Kumari for the Senior Product Manager assignment.

The demo walks through application selection, API documentation, capability selection, connector/code review, account authorization, testing, approval, activation and monitoring. It also includes test failures, recovery and a blocked write-action preview.

All data is fictional. AI generation, authorization, test results and activation are simulated. No model, credentials or external application connection is required. Downloadable code examples are illustrative, not production-ready integration code.

## Open the prototype

Use the GitHub Pages website linked in this repository, or download `index.html` and open it directly in a modern browser.

[Figma designs](https://www.figma.com/design/1Ox2ytbXh4QLWU2kCGaWxq/CloudEagle-Integration-Builder-Assignement)

## Hosting

The site is a self-contained HTML file. GitHub Pages serves the `main` branch from the repository root. No build step or dependencies are needed.
